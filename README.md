**HR Analytics Dashboard**

**Project Overview**
Developed an interactive Power BI dashboard to analyze employee attrition, workforce demographics, salary distribution, job roles, and employee retention trends.

**Tools Used**

- Power BI
- Excel

**Key Metrics**

- Employee Count
- Attrition Count
- Attrition Rate
- Average Salary
- Average Age
- Average Years at Company
   
**Dashboard Features**

- Department-wise Attrition Analysis
- Age Group Analysis
- Salary Slab Analysis
- Education Field Analysis
- Job Role Analysis
- Gender Analysis
- Employee Retention Trends
- Interactive Filters and Visualizations

**Skills Demonstrated**

- Data Cleaning
- Data Transformation
- DAX Measures
- Data Visualization
- HR Analytics
- Business Insights
